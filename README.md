## 🚀 Projects

### 🛰️ Glacial Lake Detection using Deep Learning — GLOF Challenge, SNU Chennai *(2026)*
Built a **UNet++ segmentation pipeline** with an EfficientNet-B3 encoder to detect glacial lakes from multispectral satellite imagery (RGB + NDWI as a 4th input channel). Used combined Focal + Dice + Boundary loss to handle extreme class imbalance, with CutMix augmentation and multi-checkpoint TTA ensemble for robust inference. Evaluated using IoU, Dice, F1-Score, Specificity, and Cohen's Kappa.

### 🏠 Computer Vision — YOLO Floor Plan Analysis *(Ongoing Research, 2025)*
Developing a research paper on floor plan detection using a **customised YOLO model** enhanced with attention mechanisms. Applying signal processing techniques for better feature extraction and evaluating with IoU, precision, and recall.

### ⚙️ FPGA Conveyor Belt Control System
Designed and implemented a conveyor belt control system on an **FPGA** using **PWM signal generation** to manage speed and direction — covering digital logic design, control strategy, and system-level analysis.

### 🚗 8051 Line Follower Robot
Built an autonomous **line follower robot** using an 8051 microcontroller and **infrared sensors** for real-time path tracking.
